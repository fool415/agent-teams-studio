### 认证与防爆破规则
* **哈希算法**：SQLite WAL 存储 `bcrypt (cost=12)` 哈希，磁盘零明文密码。
* **会话 Cookie**：登录后签发随机 Token，写入 `HttpOnly` + `SameSite=Lax` Cookie，有效期 **30 天**（`MaxAge = 30 * 86400`）。
* **防爆破冷却**：同一来源 IP 在 `10 分钟` 窗口内连续登录失败达 **`5 次`**，自动锁定 **`15 分钟`**（AI 指导用户排查登录失败时**切勿连续盲试密码**）。
* **自助改密要求**：登录后可通过网页右上角「🔑 改密」（后端 `POST /api/auth/password`）修改密码，**密码长度至少 6 位**。

## 三、NovixLink（诺联 `us-la-novixlink`）节点规格与策略红线

AI 在分析流量、速度或商家风险时，应以以下实测配置为基准：

* **基础设施**：美国洛杉矶（LAX），`1 vCPU / 956 MB RAM / 20 GB NVMe / KVM`，AS2914 NTT 原生双 ISP 家宽（回程电信/联通 AS9929 + 移动 CMIN2 优化）。
* **代理协议特征**：`VLESS + TCP:443 + REALITY + Vision (纯 IPv4)`，伪装源站 `SNI: mirrors.ocf.berkeley.edu`。
* **流量配额与双向计费口径（重要）**：
  * `traffic_multiplier = 2`（**双向计费 ×2**：所有上行 + 下行流量均按双向乘数纳入统计并与配额比对）。
  * 整机月流量上限：`node_cap_gb = 1000 GB`（每月 **`6` 号**重置）。
  * `zkl` 个人配额：**`750 GB / 月`**（每月 **`6` 号**重置）。
  * **服务有效期与分摊参考**：已年付缴清至 **`2027-12-06`**；`zkl` 计费规则为诺联双人 AA（`50%`），即按整机 `C$121.29 CAD / 年` 分摊 `C$60.65 CAD / 年`（折合约 `$3.54 USD / 月` ≈ `¥23.71 CNY / 月`，另有首月体验分摊 `C$6.50 CAD` 已结清）。
* **端口天井与建议红线**：
  * 标称端口 `150 Mbps`，物理口实测峰值约 **`~117 Mbps`**。
  * **公平使用建议红线**：建议 `12h 均速 < 80 Mbps`（历史连续跑满 `110M+` 曾触发宿主机长时间 FUP 抢核降频，反映为面板 `CPU Steal` 飙高）。
* **两级带宽占满自动防护 (`bw_policies` 线上实时策略)**：
  * **🟢 满速护航态 (`normal`)**：维持原生 `root fq` 队列，无人工限速。
  * **🟡 一级温和限速 (`stage1_20m`)**：当端口实时吞吐 **持续 `≥ 95 Mbps` 达 `60 秒`**，自动通过 `tc HTB + fq_codel` 限速至 **`20 Mbps`**；速率平稳回落连续 **`120 秒`** 后**自动卸载限速恢复满速**。
  * **🔴 二级死锁熔断 (`stage2_100kb`)**：进入一级限速后若仍持续顶满 **`600 秒（10 分钟）`**，判定为失控下载/拉流死循环，自动压降至 **`800 kbps`（约 `100 KB/s`）** 死锁保护；**不会自动恢复**，必须使用 **`novixlink`** 账号（或联系管理员 `root`）手动解除。
* **数据采集与同步频率**：
  * 后台默认每 **`1 分钟`** 自动增量同步各节点状态与细粒度遥测。
  * 使用 `novixlink` 账号时，可在网页顶栏点击 **「⏱️ 15m 极速观察窗」**（切换高密观察模式）或 **「⚡ 立即同步节点」**。

## 四、`@VpsPingBellBot` 机器人全功能与指令规范

### 1. 绑定与多身份热切换机制（核心用法）
`tg_bindings` 表原生支持 **1 个 Telegram 会话绑定多个面板账号**，强烈建议引导 `zkl` 将两个号全部绑定至同一个 TG：
1. **免密 6 位绑定码（推荐）**：
   * 网页登录目标账号后点击右上角 **「🔗 绑定 TG」** -> 系统生成 **6 位数字一次性绑定码**（有效期 **`300 秒 / 5 分钟`**）以及 Deep Link `https://t.me/VpsPingBellBot?start=bind_<6位码>`。
   * 在 TG 发送 `/bind <6位码>` 即完成绑定，密码全程不经过 TG 聊天记录。
2. **账密直绑（备用）**：
   * 私聊 `@VpsPingBellBot` 发送 `/bind zkl <YOUR_MEMBER_PASSWORD>` 或 `/bind novixlink <YOUR_OPERATOR_PASSWORD>`（机器人接收后会主动调用 `deleteMessage` 撤回含密码消息）。
3. **身份切换与独立静音**：
   * 发送 `/switch` 查看已绑定的账号列表并点击内联按钮秒切主身份；每个账号可独立切换 `🔔 开启 / 🔕 静音` 通知推送。
   * 发送 `/unbind [账号名]` 解除指定账号绑定。

## 五、Web 控制台功能拆解与 AI 辅助 SOP

### Web 顶栏与功能区对照（按实际渲染规则 · 已含 v4.4「优化查看体验」看板）
* **全角色置顶「🚀 即时可用性与体验看板」（位于顶栏下方，支持折叠并记住折叠状态）**：
  * **接口与权限隔离**：前端通过 `GET /api/experience`（支持 `?region=&isp=&mode=auto` 临时预览）读取；`zkl` (`member_pure`) 仅见诺联个人双向配额与可用性（`can_unthrottle: false`，严格零整机总账/他人数据），`novixlink` (`node_operator`) 可见整机月包占用并解锁限速按钮；`POST /api/auth/preferred-route` 将常用路线持久化到服务端数据库（限时访客模式保存在浏览器 `localStorage`）。
  * **常用路线加权识别**：后台读取授权范围 `ops_15m` 中的大陆直连记录（排除非大陆 `relay` 中转占位），按 **`70%` 近 24 小时权重 + `30%` 全量历史权重** 自动选出主用省市与运营商；若尚无大陆流量记录，默认兜底 **`广东移动` (`gd` + `cm`)**；点击右上角「📍 常用线路 ▾」可手动切换 31 省+港澳台 × 电信/联通/移动并一键恢复自动分析。
  * **1 小时平滑探针与优化档位**：对最近最多 4 个 `trend_15m` 采样窗口取均值降低 5 包单次突波误报，同时结合 `ret_route.core_tag` 与 ASN 输出路线档位（如 `✨ 精品优化 · 回程 CMIN2 / AS9929`）；若登录多节点账号则自动标出 `🏆 首选推荐`。

### 给 AI 的标准排障 SOP（遇到用户提问按此顺序回答）

1. **用户反馈“好卡 / 断流 / 突然只有几十 KB”**：
   * Step 1：先让用户在 TG 发 `/why` 或网页点 `🩺 自助排障`。
   * Step 2：如果确认触发 `stage2_100kb`（锁 `~100 KB/s`）或 `stage1_20m`（限 `20M`），先提示**停止本机多线程下载/测速工具**；然后引导其在 TG 发 `/switch` 切为 `novixlink` → 发 `/guard` → 点击 **「🔓 立即解除 us-la-novixlink 限速」**（或用 `novixlink` 登录网页点击解限）。
   * Step 3：若非限速，用 `novixlink` 检查 `/node` 中的 **`CPU Steal`、`24h SLA`、伪装源站 `mirrors.ocf.berkeley.edu` 握手是否正常**，以及是否处于 **北京时间 `20:00–24:00` 晚高峰三网丢包期**。若机器侧全绿（`:443` 重传率低、源站正常、三网 RTT 平稳），则结论大概率在用户本地宽带/Wi-Fi/客户端路由分流。
2. **用户反馈“网页打不开”**：
   * 先确认是否通过固定收藏旧域名访问 -> 因为入口采用 Cloudflare 免域名临时隧道，重启后会换域名；让用户在 TG 找 `@VpsPingBellBot` 发送 **`/panel`** 获取当前可用 URL。
3. **用户询问“还剩多少流量 / 会不会超”**：
   * 让用户发送 `/traffic`，提醒其面板显示的已用/总额（`750 GB` 个人、`1000 GB` 整机）**已按双向计费 `× 2` 折算**，按近 3 日斜率（`Recent3dDailyGB`）乘以距 **每月 6 号** 的剩余天数即可精准判断月初清零前是否会触顶。
4. **注意时区差异**：
   * `/panel` 输出的隧道更新时间明确标注为 `CST (UTC+8)`，曲线图中的晚高峰色带对应北京时间 `20:00–24:00`；若看到后台底层采样日志时间戳，注意与浏览器本地时区核对。
